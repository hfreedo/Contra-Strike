# Contra Strike — assets de menú

Entrega vigente: kit de menú v1. Abrir **Vista_previa.html** para revisar ambas composiciones y consultar **GUIA_CONSTRUCT_2.md** para importar los PNG y conectar los botones.

- Assets: imágenes separadas, incluido escudo transparente.
- posiciones_construct.csv/json: ubicación y tamaño para la ventana original 854×366 y la referencia 1280×720.
- inventario.json: dimensiones y hashes.
- prompts.json: prompts finales y referencias de generación.

El proyecto original permanece sin cambios. El kit prepara el menú; no implementa la jugabilidad, una condición de victoria ni reemplaza el sprite jugable del CAPX.
